## TL;DR — a fórmula, nas palavras do próprio Ed

O Ed enuncia a macro-fórmula dele literalmente (script 22):

> *"**Hook, intro, set up a problem, say the video will solve it, tell a story or give an example that prove it works, and then just show people how to do it themselves, and repeat.** That's it."*

Tudo o resto neste documento é o detalhe de cada uma destas peças. O motor narrativo por baixo é (script 04/38):

> **STORY (prova que resulta) → FRAMEWORK (passos para o viewer replicar).**

E a tese estratégica de 2025/26 que atravessa tudo: **confiança > viralidade**, e o teu valor é aquilo que a **AI não consegue copiar** — a tua experiência vivida, as tuas histórias, a tua certeza ("fingerprints").

## 1. AS PEÇAS INVARIANTES (estão em ~todos os 50, qualquer que seja o formato)

Independentemente do formato do vídeo, estes elementos aparecem quase sempre:

1. **Hook nos primeiros 10–15s** que abre um loop (efeito Zeigarnik).
2. **Promessa + roadmap** logo a seguir (tricolon: 3 coisas) com **nome do sistema + número de passos**.
3. **Credibilidade embutida e curta** (número/resultado real, nunca um parágrafo de bio).
4. **Frameworks/conceitos com NOME próprio** (uma metáfora nova por vídeo, às vezes duas).
5. **Histórias e exemplos concretos** com nomes e números reais (specific > vague).
6. **Tratamento de objeções dentro do fluxo** ("But, Ed...").
7. **Open loops em cascata** entre secções.
8. **CTA para o próximo vídeo** no fim — sempre. (+ piada/sign-off assinatura.)

> **Variável:** se o vídeo entrega ou não um *sistema replicável passo-a-passo*. Os formatos de ensino/teardown entregam; os de manifesto/diário são narrativa pura. O esqueleto de 7 blocos é a espinha do **ensino**, não uma lei universal.

## 2. OS 8 FORMATOS (cada um com o seu esqueleto)

O Ed roda um conjunto pequeno de formatos. Identifica qual estás a fazer antes de escrever.

### 2.1 Deep-Dive / Sistema (o canónico — o mais comum)
*Ex: 13, 20, 26, 31, 35, 38, 41, 44, 46.*
```
Hook (resultado + paradoxo + nega caminho óbvio + promessa)
→ promessa+roadmap (tricolon + nome do sistema + nº de passos)
→ credibilidade curta ("deixa-me garantir que ficas convencido")
→ debunk do método complicado padrão (strawman / diagrama)
→ reveal do framework (metáfora-mestra)
→ passos numerados — cada um: nomear → princípio → história/demo → objeção → transição
→ secção de prova de negócio (dados RevTrack) ou clímax emocional
→ CTA para o próximo vídeo + sign-off cómico
```

### 2.2 Teardown / Coaching ao vivo
*Ex: 03, 19, 21, 45, 47.* Aplica o sistema canónico a um canal/sales page REAL.
```
Cold-open (muitas vezes o título a meio de uma frase, ou um testemunho do cliente)
+ prova de volume ("1.800 canais submetidos", "700 negócios")
→ apresentar o sujeito real + os 3 problemas dele (= roadmap)
→ aplicar o sistema aos ASSETS reais dele (ler/tocar o conteúdo em voz alta, dissecar, reescrever antes/depois)
→ números/calculadoras ao vivo
→ CTA (ou, p. ex. no 21, fecho com testemunho emocional do cliente em vez de próximo vídeo)
```
Sub-variantes: **diálogo a dois** (21 — o cliente responde, a transformação acontece on-camera); **árvore de duas vias** (23 — modelo A vs modelo B).

### 2.3 Listicle
*Ex: 29 (5 AIs), 33 (19 lições).*
```
Hook de credibilidade/escala → anunciar a contagem ("5 AI" / "19 lições")
→ itens numerados, cada um auto-contido
→ CTA
```
Item de lição (33): pergunta/problema relatável → **uma metáfora concreta** ou história curta → a lição. Item de ferramenta (29): nome → problema que resolve → demo ao vivo → "o processo simples" → ressalvas/preço → transição. Truques: **sub-vender o item 1** ("este não é o mais brutal"); uma metáfora por item.

### 2.4 Roast / Review (research)
*Ex: 34, 40, 47.* Um rubric/checklist aplicado a 3 submissões reais.
```
Hook ("Estudei N / 1.800 candidataram-se") → gimmick de stakes (ex: "$1.000 se a AI me apanhar a falhar")
→ por sujeito: mostrar problema → correr o rubric fixo → reescrever/corrigir ao vivo → comentário em 2ª pessoa
→ CTA que recruta as próximas submissões
```

### 2.5 Diagnóstico / "Sinais" (checklist de auto-avaliação)
*Ex: 48 ("EVERYTHING You Need..."), e os "12 sinais de que estás pronto".*
```
Hook ("Será que estás pronto?") → framework de orientação (triângulo de nicho)
→ N sinais em sequência (cada um: nome → porque importa → benchmark)
→ reassurance → CTA
```
Ensina **sinais a VERIFICAR**, não passos a fazer.

### 2.6 Narrativa / Diário (story-forward)
*Ex: 18, 25, 49.* A história É o vídeo; o framework aparece no fim como "lições".
```
Hook (decisão/resultado) → o plano/setup
→ relato cronológico na 1ª pessoa, com falhas reais e artefactos (mensagens do pai, cartão de memória corrompido)
→ "aprendi N coisas" (framework destilado no fim)
→ CTA
```
Registo: keynote/vulnerabilidade, não tutorial. Motor = **fear-reframe** (inverter o medo do viewer no medo maior da inação — 25).

### 2.7 Newsjack / Análise de feature
*Ex: 09, 27, 37.* A atualidade é o hook.
```
Hook ("Saiu isto / mudou isto — e tem dois gumes")
→ contexto/história → como funciona → a falha escondida (ângulo contrarian)
→ o método correto → ressalva de contenção ("não uses features só porque existem")
→ CTA
```

### 2.8 Live Build / Challenge (muitas vezes com cronómetro)
*Ex: 43, 50.* O Ed executa o método on-camera em tempo real.
```
Hook (novo método + "vamos pôr o cronómetro a contar — 3 horas")
→ execução passo-a-passo ao vivo, com outputs verbatim (backstories, títulos, intros) narrados
→ prós/contras/expectativas por artefacto
→ CTA
```

## 3. O HOOK (primeiros 10–15s) — a peça mais crítica

Teoria do próprio Ed (script 22) — **efeito Zeigarnik**:
> *"people remember interrupted tasks better than completed ones... hooks open a loop making the audience feel compelled to continue watching so they can close it. Creating curiosity is the most powerful YouTube hack."*

### 3.1 As 5 fórmulas de hook que o Ed ensina (verbatim, script 22)
1. **"Do you want to hear something completely insane?"** (ou *"...that's going to blow your mind?"*) — quem diz que não? Mas o que vem a seguir tem de cumprir.
2. **"Can I tell you a secret?"** — desejo de informação exclusiva + sensação de pertencer a um círculo interno; já tem estrutura de história (incógnita → descoberta → revelação).
3. **"Why is nobody talking about X?"** — sugere algo importante a ser ignorado; dispara FOMO; questiona o status quo.
4. **"Imagine [um cenário vívido]..."** — é quase impossível NÃO imaginar quando nos mandam. (*"Imagine if one sentence could win your ex-boyfriend back."*) Re-engaja o cérebro.
5. **"This is why you [X]."** — adivinha o grande problema do viewer e insinua que tens a resposta (*"this is why you can't focus"*). Tem de ser algo muito comum, senão vira anti-hook.

### 3.2 Os 6 "ingredientes" de hook (taxonomia — mistura sempre 2–3)
- **A) Paradoxo/contradição** *(o mais usado)*: *"never coded... yet six figures"* (01); *"getting views, but killing her sales"* (03); *"$7M and I don't post to social media"* (30); *"turned OFF my YouTube ads"* (37).
- **B) Prova empilhada (números)**: *"$40k... $100k... six videos"* (06); *"700 businesses... $4.5M this year"* (13); *"tracking sales from 1 billion views"* (15).
- **C) Pergunta-dor + prova pessoal**: *"how can you grow when there's no time? Well, I was there..."* (05).
- **D) Autoridade emprestada + pergunta contrarian**: nomes famosos (Bartlett, Hormozi, Dan Koe) (02, 38).
- **E) Demo / before-after ao vivo / on-screen artifact**: *"see that red line going down the graph?"* (12); *"47,000 views vs the old 14,000"* (32).
- **F) Analogia/metáfora como abertura** *(novo — dominante no #22)*: quase todas as cartas abrem com uma analogia física vívida (Whac-A-Mole, lupa a queimar papel, escorrega seco = fricção, bloco de ouro por $1, menu grego = oferta desalinhada).

### 3.3 A receita-base do hook
```
[RESULTADO específico e concreto]
  + [ELEMENTO QUE NÃO BATE CERTO — paradoxo / número absurdo / contradição]
  + [NEGAR o caminho óbvio — "não foi por SEO / ads / niching down"]
  + [PROMESSA implícita: "e eu vou mostrar-te como"]
```
Sub-tipos úteis: **"old-way tricolon"** (lista 3 abordagens aceites e nega as três — 10); **"it shouldn't be possible"** (contraste com benchmark: *"a média demora 18 meses... o Greg fê-lo em 4 semanas"* — 17); **"ameaça competitiva"** (*"could stop anyone else getting traction in your niche"* — 11); **"time-bound contract"** (*"Give me 5 mins"* — 24).

### 3.4 Regras do hook
- **Específico mata vago.** Sempre "$40k em 1 mês", nunca "muito dinheiro". Especificidade = credibilidade.
- **Antecipa o cético dentro do hook**: *"That sounds like utter internet marketing talk. Here's the raw transparency of it."* (39).
- **Para negócios, podes REPELIR de propósito**: usa palavras que chamam o teu avatar e afastam os outros ("sales", "leads", "offer") — sacrificas retenção para filtrar compradores (22).
- **15 segundos é o limite.** *"if you can't hook people in the first 15 seconds, nobody's going to see [the rest]."* (07).

## 4. INTRO + SETUP (logo após o hook, ~30s)

O Ed (22):
> *"think about your intro as trying to make viewers as curious as possible... set up the massive value and results people will get if they stick about. This needs to be done in 30 seconds or less."*

- **Promessa em tricolon** ("vou mostrar-te X, Y e Z") + **nome do sistema + número de passos**.
- Para deep-dives: *"don't list 100 things, just pick the big three"* (anti-padrão: o Simon Squibb a listar 60s de tópicos — *"by the time he gets to the sixth thing, you just want to skip"*).
- **Raise the stakes + quebra crenças limitadoras** (template Thomas, 22): torna o protagonista improvável ("mau a matemática, velho, disléxico") → *"raising the stakes makes content more interesting"* + quebra a crença "isto não é para mim".
- **Re-hook**: depois do setup, volta a abrir curiosidade ("mas no processo descobrimos um método que até *ele* conseguiu seguir").
- **CTA cedo, não só no fim**: di-lo **antes dos 40% do vídeo, idealmente nos primeiros 90s** (22 — o erro confessado dele foi promover o email só ao minuto 19).

## 5. A UNIDADE-BASE DE CADA PONTO (a engrenagem que repetes "10, 20, 30 vezes")

O micro-padrão de cada passo/secção (refinamento do script 14/34):
```
1. Nomear o passo/ponto
2. SETUP do PROBLEMA que o viewer também tem  ("Wait, why do I need this?")
3. PROVA rápida de que a solução resulta  (dentro da própria história/exemplo)
4. INSTRUÇÕES  (os passos concretos)
5. Tratar a objeção + transição (open loop para o próximo)
```
O Ed enuncia-o (34):
> *"set up the problem your viewers have too, so they know why the following information matters. Then give them some proof it works quickly. And then just list your instructions."*
(*"sem o problema é como ler a folha de montagem de uma secretária IKEA sem saber porque precisas de uma secretária."*)

### Raise & Release Tension (o motor de atenção, script 34/22)
- **Build:** introduz um problema → explica porque é significativo (sobe os stakes) → entrega a solução **gradualmente** (não dês a solução já — *"é como contar a punchline da piada primeiro, insatisfatório"*).
- **Release:** dá a solução → explica-a → mostra como aplicar (história de alguém a aplicá-la).
- **Quando um ponto está resolvido, a tensão cai → levanta-a IMEDIATAMENTE** com a pergunta seguinte que o viewer já está a fazer-se: *"but how do you create that experience on a call? Boom. Tension's back up."*
- **Elementos interativos = mini-releases**: pôr algo no ecrã e pedir ao viewer "encontra o problema" → *"nearly every time I do this, I see a spike in retention where people rewatch to play the game."*

## 6. STORYTELLING — o sistema completo (scripts 38 + 22)

Tese: *"people don't remember what you said, they remember how you made them feel."*

### 6.1 O Story Circle (estrutura de qualquer história)
```
Início (problema + a dor relatável que o viewer também tem)
→ Struggle / CONFLITO no meio (o que correu mal a tentar resolver)
→ Solução (como ultrapassaste)
→ Transformação (acabas numa posição muito diferente do início)
→ Lição (uma frase)
```
> *"Start with a problem and the relatable pain your viewers have too. Show the struggle and how you went on to solve it. End on the transformation and then summarize the lesson. That's it."*

Regras do Story Circle:
- **Sucesso ou falha é irrelevante** — só precisas de mostrar transformação/lição (ex: história "rage → empathy").
- **Twist no fim** = a história definitiva (*Sixth Sense*, *Fight Club*, *Usual Suspects*).
- **Relatável ao ONDE o viewer está agora**, não impressionante-mas-distante (*"o Musk é relatável para quem luta para tirar UM negócio do chão?"*). Usa as tuas histórias, não as de famosos.
- **Abraça o quanto eras mau** (vulnerabilidade) — *"nobody likes the story of the rich person who had the easiest life. There's no lesson, no transformation."*
- **Uma lição por história** (mantém simples).
- **Apaga qualquer linha que não afete o final** (sem entulho à Chekhov): *"If you can delete a line and it doesn't impact the end, you must get rid of it."*

### 6.2 Os 3 Atos (que tipo de histórias contar — script 38)
Mapeia cada história a um ato; tenta ter ≥1 do Ato 1 por vídeo:
- **Ato 1 — PASSADO: como tu resolveste o problema.** Dá credibilidade/prova de que és legítimo.
- **Ato 2 — PRESENTE: como estás a resolver o problema dos teus clientes.** Mata o "resulta para ti, mas resultará para mim?". (Sem clientes? Serve alguém que ajudaste de graça.)
- **Ato 3 — FUTURO: como estás a moldar o futuro do nicho.** "Esta pessoa está noutro nível" → a concorrência deixa de existir na decisão de compra. (Constrói algo em público e reporta.)

### 6.3 As 3 maneiras de usar história (script 22)
1. **Documentar um desafio** (a mais poderosa) — *"o que é que os teus viewers querem alcançar mais que tudo? Vai e fá-lo."* Mesmo falhando, passa uma lição.
2. **Simplificação** — em vez de "passo 1, passo 2", conta a história do problema e de como o ultrapassaste.
3. **Anedota** curta para reforçar um ponto.

### 6.4 As 3 perguntas-porteiro (não forces histórias)
*"É a melhor forma de passar a info ou é história só por história? É relatável à minha audiência? É interessante?"* — se falha, corta. *"People don't want stories. They want good stories."*

## 7. TÍTULOS — templates e regras

### Templates recorrentes (o Ed usa o próprio remédio)
1. **"The EXACT System To [resultado] (In [prazo])"** — 39, 45.
2. **"EXACTLY How [I/To] [resultado] (In [prazo])"** — 44, 49.
3. **"Copy This [Video / Style / Strategy], It'll Blow Up Your [Sales / Business]"** — 40, 42, 46.
4. **"How To [outcome] In [prazo]"** — 41.
5. **"I Studied [Nº grande] [pessoas], This Wrecks Their [outcome]"** — 47.
6. **"EVERYTHING You Need To [outcome]"** — 48.
7. **"How I'm Using [tendência/ferramenta] To [resultado]"** — 43.
8. **"X things I wish I knew before [Y]"** / **"X years of [tema] advice in Z minutes"** / **"I did X and learned this"** (22).

### Regras de título (script 22)
- **Faz títulos + thumbnail PRIMEIRO**, antes do vídeo. Se vêm com facilidade, é sinal de boa ideia (fricção baixa).
- **Rouba e valida, não inventes**: vai ao YouTube, vê quem cobriu o tópico; só faz o vídeo se houver **outliers** (vídeos muito acima da média do canal). *"se não validas 80–90% das tuas ideias com os dados do YouTube, estás a programar-te para falhar."*
- Lidera com **resultado/promessa**, não descrição. **Faz soar fácil** ("cheat codes"). **Números** chamam cliques. **Específico = credível** ("em 6 a 12 meses").
- **< 50 caracteres** (regra; "black belt" tolera ~57 se o corte ainda fizer sentido).
- **A pergunta da manhã**: *"qual o grande problema na cabeça do viewer no segundo em que acorda?"*

## 8. THUMBNAILS (packaging — afeta tudo, script 22)

- **Thumbnail + título são mais importantes que o vídeo** ("a diferença entre 1.000 e 100.000 views").
- **Simples e rápido de fazer** = cheat code. Faz sempre **várias**; usa o **teste e comparação** do YouTube (até 3 variantes — desde dez/2025 dá para testar **só título, só miniatura ou os dois emparelhados**). O YouTube decide por *watch-time share*, não CTR — pode suprimir views durante o teste.
- **Thumbnail de dissonância cognitiva** (texto): cara simples + afirmação contrarian de ≤4 palavras ("You don't need 8 hours sleep"). *"informação que conflitua com a crença → desconforto → clicar para resolver."* Combina a **expressão facial com a afirmação** (acabaram os bocas-abertas exagerados).
- **Anti-regra**: *"never use visual metaphors in thumbnails. They don't work."* (Curiosamente, metáforas visuais funcionam DENTRO do script, mas não na thumbnail.)

## 9. CARGA COGNITIVA & CLAREZA (a "ciência" do Ed)

- **Working memory ~3 coisas** (demo das 3 bolas na mão, 14) → **rule of threes**: máx ~4 chunks (28).
- **Picture Superiority Effect** (34): retemos 10% do que ouvimos, **65% quando emparelhado com uma imagem mental** → relaciona tudo a uma situação comum visual (ex: "elevator music = small talk"). Teste: *"conseguiste imaginar? Então ouvi-te a ouvir-me."*
- **Reading age 12 / fala como a uma criança de 10 anos**; frases curtas; sem jargão. **Uma palavra errada afasta** ("what's an offer?" → usa "product/service" com iniciantes).
- **Não sobre-expliques**: *"sabes quem mais sobre-explica? Mentirosos."* Não repitas um ponto que acabaste de fazer. Economia de palavras.
- **Linguagem de certeza**: *"this WILL work"*, não *"this might work"* (28).
- **Back a emoção com um facto** ("satisfaz a fun police"): emparelha uma linha surreal/emocional com uma estatística (*"342% mais propensos a comprar"*) para os lógicos aceitarem (34).

## 10. POSICIONAMENTO & DIFERENCIAÇÃO (porque é que te escolhem)

- **Niche UP, não niche down** (06): sobe ao top 1% usando a tua **backstory** (o que construíste ANTES do YouTube). Toda a gente fez niche down → tornou nichos pequenos tão competitivos como grandes.
- **A trifecta de "ser novo" → positioning statement** (21, 26): **backstory única + uma crença contrarian + um inimigo**. Frase: *"I help [X] get [Y]."*
- **Inimigo + lovers-AND-haters** (26): *"It's just as important to be hated... when people hate you, the people who love you bond even more."* Todos os grandes personal brands têm um inimigo declarado, de propósito.
- **Os 7 tipos de gap** (16, 22): topic, age, skill, message/contrarian, process, positioning, style. *"Os que crescem mais rápido não preenchem um gap, empilham três."* (Stack 3.)
- **Sinal de que dominas um espaço**: 3 pessoas dizem o teu nome na mesma semana (21).
- **Moat anti-AI** (12, 28): a tua experiência vivida, certeza e histórias ("fingerprints") são o que a AI não consegue gerar.

## 11. CAIXA DE FERRAMENTAS — técnicas-assinatura (novas vs v1)

- **Objeção vocalizada ("But, Ed...")**: diz a objeção na 1ª pessoa do viewer e depois rebate (41, 49). Mais dramático que tratar a objeção em abstrato.
- **Concede-first / objeção a dois lados**: defende o lado oposto antes de rebater ("address the elephant in the room" — 30), ou argumenta *contra* a tua própria tese para o público errado ("turn them off? No, maybe not" — 37).
- **Demo client persistente**: inventa/usa um leitor com nome ("Steve", "Hugh", "Anna") e leva-o por TODOS os passos como exemplo trabalhado (31, 45, 50). Continuidade + relatabilidade.
- **Exemplo done-for-you verbatim**: escreve a backstory/oferta/4 intros inteiras no script ("vê-me a fazer" em vez de "eis como farias") (45, 50).
- **Técnica-como-prova-ao-vivo (meta-reveal)**: executa a técnica e depois desmascara-a — *"acabei de te dizer isto com certeza e sem te dar a fórmula, para não te subir a carga cognitiva. Vês o poder?"* (28); versão má vs reescrita ao vivo (20); contar "9 problemas" em voz alta (19).
- **Metáfora-mestra sustentada** ao longo de todo o vídeo (whiskey bar nos 5 passos — 13; chocolate/Mars bar — 44; ímã invertido — 45) + **biblioteca de metáforas partilhada entre vídeos** ("balde com um buraco" reaparece em 42, 44, 48) = coesão de marca.
- **Calculadoras / ferramentas grátis como espinha do ensino** (23, 26) — *"fiz-te uma calculadora porque qualquer um faz apps agora"* (também captura emails).
- **"Mostra a matemática"**: aritmética concreta para tornar um modelo inevitável (*"$99 curso → precisas de 1M views para $10k"* — 10; *"0.2% → 2% CTR transforma $1k em $10k/mês"* — 15).
- **Promessa de valor escalado** (retenção): *"a informação vai ficando cada vez mais valiosa à medida que o vídeo avança"* (26).
- **Seed de pay-off diferido**: planta uma instrução não explicada cedo, resolve-a tarde (*"não te preocupes com o porquê, explico na fase 3"* — 26); ou o "segredo" a meio que se revela no fim (muitas vezes = o produto) (45).
- **Clip + teardown**: toca um clip real (submetido/teu/de convidado), disseca linha-a-linha (08, 12, 17, 40).
- **Artefacto de AI/dados como prova**: mete comentários/flops num bot ou dashboard (RevTrack) e mostra o output (40, 43, 47, 49).
- **Stakes auto-impostos**: *"$1.000 a quem eu estiver a rever se a AI me apanhar a falhar"* (47); challenge com cronómetro (50).
- **De-escalação no item 1** do listicle ("este não é o mais brutal") = jogo de confiança (29).
- **Engagement-bait DENTRO do ensino**: *"comenta qual confiarias mais"* — o pedido de comentário dobra como ferramenta pedagógica (44, 45).
- **Sign-off cómico assinatura**: quase todos os vídeos fecham numa piada throwaway ou nome de uma pessoa específica (*"That was weird"*, *"You've been warned, Rob"*, *"Flipping rice cake"*).
- **Humor como ferramenta pedagógica**: fake-out anti-regras (*"a regra de ouro é acordar a meio da noite. Não, não é."* — 09), bookends temáticos (Ron Burgundy abre+fecha — 09), auto-depreciação ("stupid man with orange glasses").

## 12. CTA & MONETIZAÇÃO (a lógica de venda)

- **O vídeo nunca acaba — abre o próximo.** Padrão: [reconhece o próximo problema lógico do viewer] → [aponta o vídeo específico que o resolve]. Os CTAs formam uma **teia** (vários vídeos convergem para "deep-dives" cornerstone, p. ex. o de storytelling). Às vezes o CTA **encena** a lição (apontar para o 2º canal para ensinar a estratégia de 2º canal — 11).
- **A cadeia de 4 elos** (24, 22): views → CTA → landing page com oferta+CTA → processo de venda. Se um elo parte, não há dinheiro.
- **Vende sem ser slimy** (22, 01): o **produto é a própria educação** — usa a tua ferramenta dentro do vídeo a resolver o problema. 6 métodos: stealth mention; link em toda a descrição vendido por resultado (não "compra o meu curso"); vídeo-trailer do canal; **case study** ("o anúncio mais poderoso que farás, que não parece um anúncio"); cliente como herói; promo aberta e honesta.
- **Conversion content**: publica de graça a tua melhor versão "paga" — o viewer pensa *"isto era tão bom que devia ter pago; como trabalho com esta pessoa; e foi mais simples do que pensava."* (gerou $245k em 90 dias — 35/22).
- **Métrica-mãe = taxa de conversão, não views** (corrige tudo abaixo de 1%). E o canal-offer **têm de resolver o mesmo problema** (teste: estranho diz em 3s o problema do teu vídeo e da tua sales page — se não baterem, não compram).
- **CTA cedo** (antes dos 40%, idealmente 90s) + meio + fim.

## 13. O PROCESSO DE ESCRITA (a craft, script 22/34/38)

- **Escreve scripts — nunca bullet points.** *"When people say they present in bullet points, I die a little inside."* Sem script não consegues construir setups, payoff loops, histórias e metáforas fortes.
- **Editar o script demora mais que escrevê-lo.**
- **Regra de arrefecimento 24h–2 semanas**: afasta-te e volta — esqueces o que escreveste e vês logo as partes fracas.
- **"Audience effect"**: apresenta o script a uma pessoa (mesmo por Zoom). Os sinais não-verbais revelam falhas — *"80% das vezes apanho coisas que não veria sozinho."* (Ele tem coach de storytelling semanal.)
- **Apresenta sempre em voz alta** a ti mesmo.
- **Fricção = sinal de ideia errada**: se o título/thumbnail/ideia custam muito, passa para outra que se "embrulhe" com facilidade.
- **Lidera com história/exemplo, revela a lição DEPOIS**; põe texto no ecrã no FIM de cada ponto (para não fazerem skip).
- **Treina a escrita em canais de baixo risco** (emails, threads de Twitter, community) — feedback mais rápido; *"emails que performam bem dão os melhores vídeos."*

## 14. PRINCÍPIOS-MÃE (o que está por trás de tudo)

1. **Confiança > Viralidade.** Reputação que paga durante anos (02). A queda de atenção é onde se ganha mais dinheiro, se construíste confiança.
2. **Story prova, Framework capacita.** (04/38)
3. **Específico vence vago, sempre.** Números, nomes, demos = credibilidade.
4. **Dá nome às ideias.** Uma metáfora/framework com nome próprio por vídeo.
5. **Reduz a fricção** (master mental model): escolhe sempre a opção mínima-viável e de menor fricção — para criar E para vender.
6. **Goal-as-filter:** *"Isto ajuda-me a atingir o objetivo mais depressa? Se não, passa à frente."*
7. **Stack 3** (meta-padrão transversal): hooks (2–3 ingredientes), títulos (2+ categorias), gaps (3 de uma vez), obsessões (4). O poder vem de empilhar, nunca de um só.
8. **Cada linha compreensível ao viewer-alvo** (reading age 12).
9. **Moat anti-AI:** o teu valor é a experiência vivida que a AI não copia.
10. **O vídeo nunca termina — abre o próximo.**
