# Avatar & Oferta — contexto do canal

> Este ficheiro define PARA QUEM e PORQUÊ se escrevem os scripts. No framework do Ed,
> isto é o "post-it" — toda a decisão (hook, exemplos, palavras, CTA) filtra-se por aqui.

## O viewer-alvo (avatar)

**Donos de loja online a faturar €100k+/ano.**

- Já vendem. Têm tráfego, oferta validada, muitas vezes equipa pequena.
- **Não são iniciantes** — não querem "como abrir uma loja Shopify". Querem **otimizar, escalar e ser mais rentáveis**.
- Dores típicas: ROAS a cair, CAC a subir, margem espremida, dependência de paid, AOV baixo, retenção fraca, "faturo muito mas sobra pouco", caos operacional, não sei que alavanca puxar a seguir.
- Sofisticação: entendem ROAS, AOV, CVR, COGS, LTV, CAC, MER. Podes usar estes termos sem explicar.
- Idade aprox.: 28–50. Lêem/ouvem conteúdo de negócio. Já viram "gurus" a mais — desconfiam de hype.

> Regra do Ed: **"every line understandable to the target viewer"** — aqui o nível é alto, mas a CLAREZA continua a mandar. Simplifica o complexo; não infantilizes.

## A oferta (porque existem os vídeos)

**Serviço de performance marketing para lojas online** — ajuda lojas a **atrair, converter e reter** clientes.

- Os vídeos são o topo do funil: aquecem donos de loja até quererem trabalhar contigo.
- O CTA orienta-se a **leads/calls/aplicações** (sem ser slimy).
- **Princípio-chave do Ed (alinhamento canal↔oferta):** o problema que o vídeo resolve TEM de ser o mesmo problema que a oferta resolve. Se o vídeo é sobre "organizar o stock" e a oferta é "performance marketing", ninguém compra. Os vídeos devem viver no território **atrair / converter / reter** (aquisição paga e orgânica, CRO, email/retention, AOV, escala rentável).
- **Produto como educação:** sempre que possível, mostra o teu método/processo a resolver o problema DENTRO do vídeo. O vídeo é a melhor demonstração do serviço.
- **Cada vídeo tem promessa específica e fecha a apontar para o passo seguinte.** O **entregável
  (lead magnet)** é **opcional e pergunta-se por vídeo** — **por defeito NÃO há**: a maioria são
  vídeos de **nutrição** que posicionam a AERO ("é isto que fazemos com os nossos clientes") e
  mandam o viewer para outro vídeo do canal. O caminho de conversão para um entregável só entra
  quando esse vídeo tem, de facto, um entregável. Ver `oferta-escada-e-lead-magnets.md`.

## Os 3 pilares de conteúdo (territórios da oferta)

Todo o vídeo deve cair claramente num destes (ou na ligação entre eles):

1. **ATRAIR** — aquisição: Meta/Google/TikTok ads, criativos, hooks, oferta de topo, tráfego orgânico, CAC.
2. **CONVERTER** — CRO: landing/PDP, checkout, AOV, bundles, upsells, prova social, copy.
3. **RETER** — retenção/LTV: email/SMS (Klaviyo), subscrições, pós-compra, churn, recompra.

## Os 3 Atos aplicados a este canal (storytelling — ver framework §6.2)

- **Ato 1 (passado):** "Como EU resolvi este problema" — resultados que geraste, erros que cometeste a gerir lojas/ads.
- **Ato 2 (presente):** "Como estou a resolver o problema de clientes" — casos de lojas que acompanhas (SEMPRE anonimizados, sem dados sensíveis: "uma loja de cosmética que faturava €X...").
- **Ato 3 (futuro):** "Para onde vai o e-commerce" — a tua visão do mercado (AI no marketing, fim do paid barato, primeira-parte data, etc.). Posiciona-te acima da concorrência.

## Posicionamento (ver framework §10)

- **Backstory + crença contrarian + inimigo.**
- Crença contrarian possível: "mais ads não é a resposta", "a maioria das lojas €100k+ está a deixar lucro na mesa na retenção", "o ROAS é uma métrica que engana".
- **Inimigo** útil: agências que só olham para ROAS de plataforma; gurus de "escala infinita"; a obsessão com aquisição ignorando retenção.

## Tom & idioma

- **PT-PT a 100%.** "Tu". Conversacional (é um vídeo falado, não um artigo).
- Anglicismos naturais do e-commerce permitidos: ROAS, AOV, CVR, COGS, LTV, CAC, MER, checkout, upsell, bundle, PDP, ATC, paid, orgânico, funil.
- Direto, com autoridade mas sem arrogância. Como um operador que já viu os números de muitas lojas. Honesto/vulnerável quando ajuda a confiança (estilo Ed).
- **Casos reais sempre anonimizados.** Nunca expor nomes de clientes nem números sensíveis. Apresentar o AERO.OS / AERO pelo nome no script é natural e encorajado (quem somos + o que faz).

## PT-PT — regra rígida (zero pt-BR)

Este guião é falado à câmara em **português de Portugal**. Uma única expressão brasileira parte a
credibilidade e denuncia "texto de IA". **Não pode haver nenhuma.** Não basta escrever "em PT-PT" na
cabeça — os modelos derrapam para pt-BR por defeito. Aplica estas regras à letra e faz a revisão final (a seguir).

**1. Tratamento e imperativo — o maior denúncia.** Sempre "tu" com 2ª pessoa, nunca "você" com 3ª.
Imperativo na forma de "tu", não na de "você":
- ✅ `faz`, `vê`, `clica`, `pega`, `olha`, `repara`, `imagina`, `pensa`, `diz` · ❌ `faça`, `veja`, `clique`, `pegue`, `olhe`, `repare`, `imagine`, `pense`, `diga`
- ✅ `tens`, `fazes`, `queres`, `consegues`, `vais`, `sabes` · ❌ `tem` / `faz` / `quer` / `consegue` / `vai` / `sabe` (a tratar por "você")

**2. Gerúndio → `estar a` + infinitivo.** O gerúndio contínuo é o tique nº1 do pt-BR.
- ✅ `estás a perder`, `estou a mostrar`, `está a acontecer`, `continuas a pagar` · ❌ `está perdendo`, `estou mostrando`, `está acontecendo`, `continua pagando`

**3. Colocação do pronome (ênclise).** Pronome depois do verbo, com hífen; não no início.
- ✅ `mostro-te`, `vou mostrar-te`, `diz-me`, `lembra-te`, `pergunto-te` · ❌ `te mostro`, `vou te mostrar`, `me diz`, `se lembra`, `te pergunto`

**4. Léxico — traduz sempre o da esquerda:**

| ❌ pt-BR | ✅ PT-PT |
|---|---|
| tela | ecrã |
| usuário | utilizador |
| gerenciar / gerenciamento | gerir / gestão |
| planejar / planejamento | planear / planeamento |
| arquivo | ficheiro |
| estoque | stock / inventário |
| frete | portes / envio |
| faturamento | faturação |
| cadastro / cadastrar | registo / registar |
| acessar / acesso | aceder / acesso |
| deletar | eliminar / apagar |
| baixar | descarregar / transferir |
| checar | verificar |
| loja virtual | loja online |
| time (equipa) | equipa |
| celular | telemóvel |
| aplicativo | aplicação / app |
| legal (fixe) | fixe / bom |
| a gente | nós |
| pra / pro | para / para o |
| grana | dinheiro |
| galera / pessoal | malta / pessoal |
| CEP | código postal |
| R$ / reais | € / euros |
| virar (tornar-se) | tornar-se / passar a |
| pegar e fazer | é só fazer / basta fazer |

**5. Moeda e números.** Sempre `€` e euros (mercado português). Vírgula decimal, ponto de milhar
(`1.500,00 €`). Nunca `R$` nem reais.

**6. Naturalidade falada PT-PT.** Preferir construções que soem a português de Portugal falado:
`estás a ver?`, `não é?`, `pois é`, `à partida`, `de facto`, `se calhar`, `giro`. Evitar muletas
brasileiras: `tipo assim`, `né?` (usar `não é?`), `daí`, `aí você`, `beleza`, `cara`.

## Revisão final PT-PT (obrigatória antes de entregar)

Depois de o guião estar escrito, faz **uma passagem dedicada só ao idioma**, linha a linha, à procura
de pt-BR. Lê o texto **como se o estivesses a dizer em voz alta** — o ouvido apanha o que os olhos
deixam passar. Varre especificamente: (1) todo o imperativo/tratamento está em "tu"? (2) algum gerúndio
contínuo escapou? (3) pronomes com ênclise? (4) alguma palavra da tabela acima? (5) moeda em €?
Corrige tudo antes de mostrar. **Se ficares em dúvida sobre uma expressão, reescreve-a de forma
inequivocamente portuguesa** — na dúvida, não a deixes passar.

## Casos & dados

- Usa números concretos sempre que possível (€, %, antes/depois) — specific > vague.
- Quando não tens um número real à mão, usa cenários plausíveis e marca-os como ilustrativos ("imagina uma loja que...") em vez de inventar prova falsa.
