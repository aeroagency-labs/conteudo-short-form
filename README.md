# conteudo-short-form

Base de conhecimento da Aero Agency para escrever guiões de vídeos short-form (Reels, Shorts, TikTok) para donos de lojas online em Portugal.

Primeiro recolhe-se o conhecimento, depois escrevem-se os guiões. Este repositório guarda o conhecimento.

## Por onde começar

1. [briefing.md](briefing.md): o pedido atual, os temas e o que se quer em cada um.
2. [guia/o-que-funciona.md](guia/o-que-funciona.md): o que fez os scripts de agosto funcionarem e o que falhou em novembro, com números.
3. [frameworks/README.md](frameworks/README.md): hooks, estrutura do guião, CTA e conteúdo, com a checklist de 14 pontos antes de gravar.
4. [fontes/README.md](fontes/README.md): a matéria-prima para tirar sumo.
5. [guia/formato-app.md](guia/formato-app.md): como entregar os guiões na app Script Spot (importação em bulk).

## Estrutura

```
briefing.md                 pedido atual

  o-que-funciona.md         análise dos 48 scripts da app (abril, agosto, novembro)
  formato-app.md            campos, marcadores e formato de importação em bulk
frameworks/
  hooks.md                  tipos de hook, testes, exemplos nossos
  estrutura-do-guiao.md     hook → ponte → corpo → payoff → CTA, com tempos
  anuncios-e-cta.md         CTA e destinos (auditoria, WhatsApp, YouTube)
  conteudo-e-volume.md      o que dar de graça, volume, reaproveitamento, medir
  youtube-playbook/         framework Ed Lawrence, swipe file de hooks, regras de shorts,
                            avatar e oferta, catálogo do canal, glossário de métodos
fontes/
  scripts-app/              os 48 scripts short-form já escritos (export de 12 nov 2026)
  youtube/                  18 guiões de vídeos longos com "sumo para shorts"
  black-friday/             Regra do Empate, masterclass, números 2026, conector Peak Season AI
```

## Regras de uso

- Números só com fonte neste repositório. Sem fonte, não entra.
- Notas sobre livros de terceiros estão escritas por palavras nossas; não colar texto dos livros aqui.
- Notas marcadas com (†) em `frameworks/` vêm de um capítulo que não foi lido do PDF (veio truncado) e precisam de confirmação.
