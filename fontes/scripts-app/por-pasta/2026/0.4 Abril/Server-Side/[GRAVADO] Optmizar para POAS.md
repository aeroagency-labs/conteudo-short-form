# Optmizar para POAS 

- **Pasta:** 2026 / 0.4 Abril / Server-Side
- **Categoria:** Server-Side
- **Estado:** Gravado (gravado em 2026-04-18)
- **Criado:** 2026-04-17

## Hooks

1. Tens uma loja online e estás a otimizar para ROAS? Estás a otimizar para a métrica errada.
2. Se tens uma loja online, a Meta não sabe quanto ganhas por venda.
3. Estás a escalar faturação numa loja online… sem controlar o lucro.
4. Se geres uma loja online, o algoritmo pode estar a vender os produtos menos rentáveis.
5. Se tens uma loja online, estás a dar os dados errados ao algoritmo todos os dias.

## Script

A realidade é esta.
As plataformas estão a otimizar com base na faturação.

Mas faturação não é lucro.

E como o algoritmo não vê os teus custos,
vai empurrar os produtos que vendem mais fácil,
não os que te deixam mais dinheiro.

Com server-side, isso muda na base.

Passa a ser possível enviar o lucro real de cada venda
diretamente para a Meta e para o Google.

E quando isso acontece,
o algoritmo começa a otimizar para o que interessa.

Produtos mais rentáveis.
Clientes mais valiosos.

Resultado?
Mais margem no final.
