Matéria-prima para os guiões. Nada aqui é para gravar tal como está; é para tirar sumo.

| Pasta | O que tem | De onde veio |

## Como usar

1. Escolhe o tema do short.
2. Procura o sumo: primeiro em `youtube/` (vídeos longos recentes), depois nos scripts gravados de agosto em `scripts-app/` (os melhores), depois em `black-friday/`.
3. Escreve seguindo [../guia/o-que-funciona.md](../guia/o-que-funciona.md) e os [frameworks](../frameworks/).
4. Usa só números que estejam numa fonte daqui. Se o número não tiver fonte, não entra.
