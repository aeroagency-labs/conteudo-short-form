# Remake | Os teus clientes não valem todos o mesmo

- **Pasta:** 2026 / 11 Novembro / Big Query
- **Categoria:** Big Query
- **Estado:** Por gravar
- **Criado:** 2026-11-11

## Hooks

1. Há três formas de fazer crescer uma loja online. Estás a usar a mais cara?
2. Um cliente compra uma vez. Outro volta todos os anos. A Meta não os distingue.
3. Os teus clientes não valem todos o mesmo. Os teus anúncios acham que sim.
4. Para de pagar para trazer clientes que compram uma vez e desaparecem.
5. Tens clientes que valem dez vezes mais do que outros. Sabes quem são?
6. A forma mais barata de crescer não é arranjar mais clientes.

## Script

Há três formas de fazer crescer uma loja online.
Mais clientes. Clientes a voltar mais vezes. Ou clientes a gastar mais de cada vez.
E a primeira é a que pagas em anúncios.

Imagina dois clientes.
O primeiro compra uma vez, gasta 20 euros e nunca mais volta.
O segundo volta quatro vezes por ano. No total, gasta 200.
Pagaste 15 euros em anúncios por cada um. Só um é que valeu a pena.

O problema é que a Meta não sabe qual dos dois vai voltar.
Ela vai buscar gente parecida com quem comprou. Seja quem for.
Por isso, o que nós fazemos é mostrar-lhe quem são os segundos.
Através de uma ferramenta chamada BigQuery, separamos os clientes que voltam e gastam mais.
E depois enviamos essa lista à Meta, automaticamente, para ela ir buscar mais iguais.

Ou seja, deixas de pagar para trazer quem compra uma vez.
E esse dinheiro passa a ir buscar quem volta.

Faz isto hoje: no Shopify, ordena os clientes pelo total gasto.
Olha para os vinte de cima.
É esse tipo de cliente que as nossas campanhas vão buscar.
