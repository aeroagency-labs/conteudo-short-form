## Hooks

1. Tens uma loja online e não tens programa de fidelidade? Estás a perder clientes.
2. Se tens uma loja online, a tua receita depende de quem volta a comprar.
3. Tens uma loja online? Então precisas de aumentar o valor de cada cliente.
4. Se geres uma loja online, cada cliente que não volta é dinheiro perdido.

## Script

A realidade é esta.

Adquirir clientes está cada vez mais caro.

E se esses clientes não voltam,
o teu lucro desaparece.

É aqui que entra um sistema de fidelidade.

Pontos, cashback, crédito em loja.

Dás ao cliente uma razão para voltar.

E quando ele volta,
o custo de aquisição dilui-se
e o valor desse cliente aumenta.

Mais compras.
Mais frequência.
Mais receita por cliente.

E o mais importante.

Deixas de depender só de tráfego pago
para crescer.
